How it works

Three steps from zero to production traffic.

  1. 01

    Issue a key

    Create an API key in the dashboard or via the Admin API. Each key is scoped to a workspace and carries its own rate limit.

  2. 02

    Define a route

    Map an inbound path to your upstream service. Add rewrite rules, headers, and authentication requirements.

  3. 03

    Observe traffic

    Watch request logs, latency, and error rates in real time. Set alerts on the metrics that matter to your team.
